# YES24 Metadata Source 0.5.5

## 핵심 변경

- YES24 상품 페이지의 `관련분류 > 카테고리 분류`를 읽어 광역 루트 아래 2단계까지 태그로 보강합니다.
- 여러 공식 분류 경로를 합치되 정확히 같은 태그는 한 번만 유지합니다.
- `소설/시/희곡`, `인문/교양`처럼 YES24가 하나의 공식 분류명으로 제공하는 `/` 포함 이름은 그대로 유지합니다.
- `수상내역 및 미디어 추천 분류`와 `이 상품의 태그`는 카테고리 보강에서 제외합니다.
- HTML comment 등 YES24 storefront 마크업 변형이 있어도 DOM 파싱 실패가 전체 검색 실패로 이어지지 않도록 raw-HTML fallback을 유지합니다.
- `978-89-329-6038-8 08890`처럼 ISBN 뒤에 5자리 부가번호가 붙은 EPUB identifier에서 체크디지트가 유효한 ISBN을 검색용으로 추출합니다. Calibre에 저장된 원본 identifier 자체는 변경하지 않습니다.
- ISBN이 YES24 Open API 검색 인덱스에서 누락된 경우 기존 제목/저자 후보 검색 fallback을 그대로 사용합니다.

## 네트워크

0.5.5는 메타데이터 후보의 공식 카테고리 보강을 위해 YES24 상품 페이지를 조회할 수 있습니다. 요청/파싱이 실패하면 Open API 메타데이터를 그대로 반환하며 검색 자체는 실패시키지 않습니다.

## 실환경 검증

Calibre 9.14 / Windows 11에서 실제 도서 검색으로 다음 동작을 확인했습니다.

- `건축으로 만나는 1000년 로마`: `역사, 서양사/서양문화, 예술, 건축, 인문, 인문/교양`
- `질문의 격`: 일반 카테고리는 보강하고 세종도서/YES24 올해의 책 계열 추천 분류는 제외
- `978-89-329-6038-8 08890` → 검색용 ISBN `9788932960388` 추출 및 실제 ISBN 검색 성공
- `978-89-329-6787-5 05170` → 검색용 ISBN `9788932967875` 추출. YES24 Open API ISBN 조회 누락 시 제목/저자 fallback 동작 확인
